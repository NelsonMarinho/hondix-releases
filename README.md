# HondiX — instalador para Windows

Sistema de gestão de oficina **HondiX**. Este repositório guarda **somente os instaladores**; nenhum dado de cliente fica aqui.

## ⬇️ Baixar a versão mais recente

**[Clique aqui para abrir a última versão](https://github.com/NelsonMarinho/hondix-releases/releases/latest)** e, em **Assets**, clique no arquivo `HondiX_..._x64-setup.exe`.

## Como instalar

1. Baixe o arquivo `HondiX_..._x64-setup.exe`.
2. Se o navegador avisar que o arquivo **não é baixado com frequência**, clique em **Manter** (Edge: “…” → Manter → Mostrar mais → Manter assim mesmo).
3. Dê dois cliques no arquivo baixado.
4. Se aparecer **“O Windows protegeu o computador”**, clique em **Mais informações** → **Executar assim mesmo**.
5. Avance até concluir e abra o **HondiX** pelo atalho na Área de Trabalho ou no Menu Iniciar.
6. No primeiro acesso, crie o **administrador** (nome, usuário e senha). Não existe senha padrão.

> Os avisos dos passos 2 e 4 aparecem porque o instalador ainda não tem certificado de assinatura digital pago. Não afetam o funcionamento nem os seus dados.

## Seus dados

- Ficam **somente no seu computador** (pasta de dados do Windows) e funcionam sem internet.
- Instalar uma versão nova por cima, ou desinstalar, **não apaga** os dados.
- Faça backups pelo próprio sistema (Configurações › Backup).

## Requisitos

Windows 10 ou 11 (64 bits). O componente WebView2 já vem no Windows atualizado; se faltar, o instalador baixa sozinho.
